# Кирилл Лукьяненко — сайты под ключ

Сайт-портфолио: лендинги, сайты компаний и интернет-магазины. Оренбург, удалённо по всей России.

Статичный сайт без сборки и зависимостей: HTML, CSS и чистый JavaScript. Шрифты и картинки лежат в репозитории, внешних запросов нет, cookie и аналитика не используются.

## Структура

```
index.html        главная страница
css/style.css     стили (светлая и тёмная тема)
js/main.js        анимации, меню, калькулятор, вопросы, форма
works/            три демо-сайта: garazh12, polka, dvorik
img/              превью работ, картинка для соцсетей, иконка
fonts/            шрифты в формате woff2
404.html          страница «не найдено»
favicon.svg       иконка вкладки
```

## Публикация на GitHub Pages

1. Загрузите содержимое папки в корень репозитория.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Адрес сайта: https://k1rluk.github.io/Portfolio/. Если подключите свой домен, поменяйте его в `index.html` в тегах `og:url`, `og:image`, `canonical` и в `robots.txt`.

## Локальный просмотр

```
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
